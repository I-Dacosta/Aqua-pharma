# Trio (Next.js project)

This is the main Next.js demo project. It uses Next.js + Tailwind.

Run locally

```bash
cd "trio"
pnpm install
pnpm dev
# open http://localhost:3000 (or the port shown by Next)
```

Add showcase images

- Put preview images in `public/imagens/` or `public/logo/` using descriptive names (e.g. `screenshot-home.png`).
- Update pages/components to reference those images where you'd like them shown.
